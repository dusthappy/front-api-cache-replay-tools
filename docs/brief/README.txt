Chrome 页面接口缓存插件 开发交接包
版本：需求基线 1.0
整理日期：2026-10-14

用途
将本目录放入本地开发项目，交给 Cursor、Claude Code 或其他编程 Agent，实现仅支持 Chrome 的扩展。
本包是开发说明与验收清单，不包含已经实现、安装或测试过的插件代码。

阅读顺序
1. DEVELOPMENT_SPEC.txt：已确认功能、交互、技术方案、数据模型与开发阶段。
2. ACCEPTANCE.txt：首版必须通过的验收场景。
3. START_PROMPT.txt：直接复制给本地编程 Agent，要求其根据上述文件实现并验证。

产品目标
本地前端调用本地后端，而后端访问远程数据库较慢。通过录制真实响应并在后续请求时本地回放，缩短重复前端调试等待。

关键体验
右上角可拖动圆按钮；点击打开当前页面接口面板；接口详情全部默认收起；列表直接操作缓存开关与重新请求。

实施范围
只支持 Chrome 桌面浏览器。首版采用 Manifest V3，面向页面内普通异步 fetch/XHR JSON 请求，无需云服务和后端代码改造。
支持范围之外的请求正常直通。

交付要求
本地执行 Agent 应交付实际源码、依赖锁文件、构建产物、加载说明及真实验证记录。不得将文档包误称为已完成插件。
