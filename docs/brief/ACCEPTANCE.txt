Chrome 页面接口缓存插件 首版验收清单

验证环境
运行两个前端路由 /users 与 /orders，以及带请求计数和访问日志的本地后端。
后端测试接口包含 GET 查询、POST 查询、创建/修改接口、鉴权接口、HTTP 错误、HTTP 200 业务失败、延迟响应。
响应回传 method、query、body、用户/租户标识和后端累计调用次数，便于验证没有误匹配。
测试页面覆盖原生 fetch、异步 XHR 和一个实际 Axios 调用路径。
受控环境关闭其他缓存并设置适当响应头，避免将浏览器 HTTP 缓存误认为扩展命中。
验收记录必须写明 Chrome 版本、扩展版本、实际执行方式；未运行的项目标未测。

A01 站点范围
配置 localhost 的一个端口，其他端口和未授权站点不出现按钮、不参与缓存。
授权范围比应用规则宽时，应用规则仍精确隔离端口。

A02 圆形悬浮入口
首次打开页面只有圆按钮。拖动不误展开；位置重载后保留；缩小窗口后按钮仍可见。
点击展开、外部点击/Escape/关闭按钮收起，页面其他交互正常。

A03 默认折叠
面板打开时所有接口详情收起，响应正文也不自动展开。
点击标题展开/收起；操作开关、重新请求、复制按钮不触发展开。

A04 页面绑定
/users 与 /orders 各显示全部已绑定接口；同一 API 可分别绑定两页。
历史绑定刷新后保留，未触发的手动接口显示未请求。
请求发出后立即换路由，响应仍归原页面，不污染新页面。

A05 首次录制与命中
开启一个 GET 查询。第一次请求计数增加一次并存缓存；第二次相同请求不增加后端计数，页面收到相同正文。
Chrome DevTools 保持打开时同样有效，扩展面板能看到 HIT。

A06 参数匹配
改变未忽略 Query 或 Body 字段应重新请求。
只改变 JSON 对象键顺序仍命中；数组顺序、字符串/数字变化应分开。
同名重复 Query 参数保持语义，字段缺失和空值不误合并。

A07 忽略参数
配置 query.page、query.pageSize，翻页返回原录制响应，后端计数不增加。
页面最近一次调用使用 page=3 后点击重新请求，真实请求仍包含 page=3；不得把忽略字段删掉。
修改忽略规则后，旧缓存不能继续按旧规则误命中。

A08 POST 和写操作
明确标记的 POST 查询可按 Body 匹配缓存。
普通 POST 创建、PUT/PATCH/DELETE 和鉴权操作始终执行真实业务，不缓存，不开放快捷重发。
接口始终直通规则不能被页面总开关或批量开启覆盖。

A09 三种时间
缓存命中只更新页面最后调用时间，不改最后真实请求时间和缓存更新时间。
真实请求失败更新尝试时间及错误状态，不改原成功缓存时间。
手动重发有独立来源，不伪装页面调用。

A10 重新请求
缓存开启时使用当前页面最近原始参数绕过扩展缓存，成功替换目标组。
多参数组合重发一组后，其他组不被覆盖。
无模板、无身份上下文、跨账号模板等情况下禁用按钮并说明原因。

A11 关闭缓存时重发
网站、页面或接口任一缓存开关关闭，手动重发仍可更新状态与预览，但不读取/写入缓存、不擅自开启开关。
重新开启后依照 TTL 使用保留缓存，不得将关闭期间结果当成已录制数据。

A12 刷新页面
重新请求不会宣称页面组件已自动更新。
缓存开启且符合录制条件时，重新请求并刷新页面必须等待成功保存；刷新后的数据来自新缓存。
缓存关闭时，等待真实请求成功后刷新，后续请求仍正常直通，不保证复用刚才的结果。
请求期间切换页面，不刷新新页面。

A13 失败和业务错误
HTTP 401/403/500、HTTP 200 业务失败、超时、取消不进入缓存。
重发失败保留旧成功响应但显示失败；已知身份失效后旧分区不可再命中。

A14 身份与环境
不同 Token、租户、页面、端口和 environmentId 不共用缓存。
登录/退出和已知身份切换使旧模板作废。
Cookie-only 未建立身份分区时不缓存登录相关数据；手动分区模式明确标示其边界。

A15 凭证
数据库、日志、导出的调试记录中没有明文 Authorization/Cookie。
手动重发 Cookie 由浏览器处理，遵守原 credentials/withCredentials。
Token 只从当前运行时上下文取得；浏览器重启后不会静默复用持久化旧凭证。

A16 在途响应
启动延迟请求后清空缓存，待响应结束缓存仍为空。
关闭再开启、规则修改、环境/身份切换同样阻止旧在途响应重新写入。
两个同键请求乱序返回，旧请求不覆盖较新的成功刷新。

A17 请求兼容性
fetch 的 json/text/clone 和 AbortSignal 正常；XHR readyState、load/error/abort/timeout、responseType=json/text、响应头读取满足测试页面。
对不支持类型旁路，不能让页面收到看似成功但格式错误的伪响应。
取消请求后晚到缓存结果不能再触发成功回调。

A18 通信/存储故障
后台休眠后重新请求能恢复读写。
模拟缓存查询超时/写入失败，页面仍正常得到原始响应，后端不因回退而重复收到同一调用。
扩展重载或桥接失效不会无限等待。

A19 持久化、TTL、容量
刷新页面、重启浏览器后绑定/规则/成功缓存存在，符合身份规则才能使用。
过期缓存重新请求；超大响应旁路；容量超限正确淘汰而非阻塞页面。
页面之间清空互不影响。

A20 信息与边界
能明确区分缓存命中、真实请求、直通原因、失败和进行中。
Worker、自主 Service Worker、WebSocket、SSE、同步XHR、上传下载和 iframe 等首版范围外请求保持原有行为。
