此 ZIP 已编译，可直接解压安装，无需 Node.js 或编译源码。打开文件页面后点击 Download raw file 下载。

1. 下载并解压 ZIP。
2. 打开 `chrome://extensions`，开启开发者模式；更新时先移除旧扩展。
3. 点击“加载已解压的扩展程序”，选择 `api-cache-replay-0.7.5` 文件夹，第一层应直接包含 `manifest.json`。
4. 添加前端网站并保存授权，再刷新业务页面。
